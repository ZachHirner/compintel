Tricentis Internship Capstone Project
Competitive Intelligence Research Agent
An automated pipeline that continuously tracks, analyzes, and delivers actionable competitive intelligence — so sales reps always walk into deals prepared.
Presented ByZach Hirner
TeamTricentis Sales Enablement
DateSummer 2025
1
The Problem
Sales reps were flying blind against competitors
📋
Research was manual & ad-hoc
When an AE walked into a deal against OpenText or UiPath, finding current intel meant hours of Googling — or going in unprepared.
⏳
Intel went stale quickly
Competitors update pricing, launch products, and shift messaging constantly. Existing docs were often months out of date.
🚨
No early warning system
When a competitor quietly updated their pricing or launched a new feature, Tricentis only found out when a prospect brought it up.
🔍
New competitors had no coverage
When a lesser-known player showed up in a deal, there was no fast way to research them. AEs were on their own.
2
The Solution
What is the CI Research Agent?

Manual effort to maintain
  • An automated scraping pipeline that collects data from competitor websites, social media, analyst coverage, and review platforms — 3 times per week on a schedule.
  • An AI analysis layer powered by Claude that synthesizes raw scraped data into structured, sales-ready intelligence reports with battle card notes, customer sentiment, and analyst positioning.
  • A delta detection system that compares each run against the last, surfacing exactly what changed — new product names, updated pricing, shifted messaging — the moment it happens.
  • A Research Agent that any team member can talk to: ask about a competitor, request ad-hoc research on a new company, or trigger the creation of new pipeline scrapers through conversation.

OutputCI Report
Scraping Layer
Selenium + stealth browser visits competitor websites, LinkedIn, YouTube, X/Twitter, Forrester, Gartner, PeerSpot, and TrustRadius. Runs Monday, Wednesday, Friday at 8:30 AM Central via GitHub Actions.
AI Analysis Layer
Claude synthesizes all raw text into a structured JSON report: executive summary, key products, positioning themes, strengths, weaknesses, and Tricentis-specific battle card notes.
Delta Detection
Every run is compared against the previous one using line-level diffs. Claude identifies exactly what wording, pricing, or product names changed and flags it in a delta report.
Health Monitoring
A separate job runs every other day checking all URLs. If pages go down or get blocked, GitHub Issues are opened automatically — no manual oversight needed.
4
The Research Agent
Beyond the pipeline — an AI analyst anyone can talk to
Three Skills
  • Scheduled Intel Reference — Pull existing reports and supplement with live web research on demand.
  • Ad-Hoc Research — Research any competitor not in the pipeline. Discovers URLs, visits sources, and produces a full structured CI report in minutes.
  • Script Generator — Automatically generates all scraper files and opens a GitHub PR to add a new competitor to the pipeline permanently — through conversation, no coding required.
What It Delivers
  • Executive summary of the competitor's current market position
  • Key products and target segments
  • Current messaging themes from website + social
  • Customer sentiment from review platforms
  • Analyst standing — Gartner, Forrester
  • Battle card notes: where Tricentis wins, where they win, discovery questions, and suggested talk tracks for AEs

Future Vision
How this project can evolve
🔌
Proxy Integration
Integrating a rotating residential proxy service (Zenrows, ScraperAPI) would dramatically increase the percentage of competitor pages that return real content — review sites, analyst pages, and paywalled resources currently blocked.
💬
Slack Integration
Push delta alerts and new reports directly into a Tricentis Slack channel. An AE could type /intel uipath and receive a battle card in seconds — no GitHub, no browser, no manual lookup.
📊
Showpad Integration
Auto-generate battle card PDFs after each analysis run and push them directly to Showpad via their REST API — updating the existing published asset in place. Sales reps always find the current version. Zero manual uploads, zero stale decks.
📈
Trend Tracking
The timestamped data structure already captures every historical run. A trend layer would visualize how a competitor's messaging, pricing, or headcount changes month over month — turning snapshots into a longitudinal feed.
🌐
Unlimited Competitor Coverage
The Script Generator skill makes adding any new competitor a one-conversation operation. As Tricentis encounters new players in deals, the pipeline grows to match — no engineering sprint required.
